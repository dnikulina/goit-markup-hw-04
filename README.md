## Overview

This stage of the WebStudio project adds visual effects and interactive states to the existing layout.

## Tech Stack

- HTML5
- CSS3
- Flexbox
- CSS Transitions
- Background Images
- Git & GitHub

## Implemented Features

- hero background image;
- active navigation state;
- hover and focus effects;
- CSS transitions;
- decorative positioning;
- improved portfolio card presentation;
- refined visual styling across page sections.

## Learning Outcomes

- hover and focus states;
- transitions and interaction feedback;
- background images;
- pseudo-elements and decorative effects;
- absolute positioning;
- refining an existing interface without changing its core structure.
